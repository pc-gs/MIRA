# Security policy

Mira runs locally, asks for Screen Recording (zoom) and registers global shortcuts. If you find a way it could leak screen contents, keystrokes or anything else from a user's Mac, please report it privately.

Use **GitHub → Security → Report a vulnerability** on this repository (private vulnerability reporting). Please don't open a public issue for security problems.

Only the latest version on `main` is supported. You'll get an answer within a few days.
